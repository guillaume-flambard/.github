# .github

Default community health files for every repository this account owns that does
not carry its own.

This repository is intentionally small. It holds only what is genuinely the same
everywhere: how to report a defect, how to shape a pull request, and where
support questions go.

It deliberately does **not** hold a `CONTRIBUTING.md` or a `CODE_OF_CONDUCT.md`.

A default file applies only where the repository is silent, so a generic
contribution guide here would quietly become the contribution guide of any
project that has not written its own. Several of these projects have a real
admission rule, a pre-registered evidence discipline, or a code of conduct with
an enforcement contact. Those are not generic and they are not ours to
approximate. Each of those repositories carries its own.

Precedence on GitHub: the repository's `.github/` folder, then its root, then
`docs/`, then this repository.
