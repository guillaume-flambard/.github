# Support

Questions, ideas and architecture discussion belong in the repository's
Discussions, not in Issues. Issues carry defects, regressions and accepted
tasks; Discussions carry everything that has not earned that status yet.

For a defect, use the issue template. It asks for the version, the environment
and a reproduction, because those three are what make a report actionable.

Vulnerabilities never belong in a public issue. See `SECURITY.md`.
